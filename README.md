# Craftseer

Craftseer is a language game for developing ideas through structured word choice, relationships, critique, and revision.

The player represents a subject using a chosen set of elements, connects them with relationships, composes a statement, and iteratively improves it. Each element, relationship, critique, and improvement is expressed in a single word.

The aim is not merely to produce a better statement, but to discover what makes it better.

## How to play

1. Choose a subject and establish the aspects to represent.
2. Populate each aspect with a single word.
3. Connect the elements using single-word relationships.
4. Compose the elements and relationships into a statement.
5. Critique every element and relationship using a single word.
6. Improve criticised items while preserving what already works.
7. Reassemble the statement and repeat while useful.

The player may introduce additional constraints for a particular game.

## Files

- `rules.md` — the rules and guiding principles of play.
- `template.md` — a reusable conversation scaffold.
- `rubric.md` — criteria for evaluating quality, recognition, failure, and revision.
- `demonstration/` — an example conversation showing the game in practice.

## Guidance for agents

Follow `rules.md` during play, use `template.md` to establish the initial sequence, and consult `rubric.md` to guide judgement. Treat the demonstration as an example, not a rigid script.

Elicit the player's own discoveries rather than supplying conclusions prematurely. Enforce constraints consistently, and distinguish a player's explicit recognition from an inference about what they may have realised.
